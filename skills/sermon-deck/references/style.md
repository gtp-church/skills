# Замеры стиля

Всё ниже снято с готовых презентаций общины (эталон — самый свежий файл папки
референсов). Числа уже зашиты в `deckbuilder.py`; этот файл нужен, если
понадобится новый тип слайда или захочется понять, откуда взялись значения.

## Холст и цвета

| | |
|---|---|
| Размер слайда | 12192000 × 6858000 EMU (13,33 × 7,5", 16:9) |
| Фон | прямоугольник на весь слайд, заливка `schemeClr tx1` (чёрный) |
| Основной текст | `schemeClr bg1` (белый) |
| Акцент | `srgbClr FFFF00` (жёлтый) |
| Логотип | 541871 × 541871 EMU в точке (11508153, 6131169) — правый нижний угол |

Тема шаблона — стандартная Office: `tx1` = чёрный, `bg1` = белый. Поэтому фон
и текст задаются через тему, а не через RGB: если общине когда-нибудь захочется
инвертировать колоду, это будет одно изменение в теме.

## Шрифты

| Шрифт | Где |
|---|---|
| `Akrobat Bold` | заголовки разделов, пункты списков, крупные мысли, стихи |
| `Heading Pro` | титул, жёлтая плашка раздела, подпись автора гимна |
| `Heading Pro ExtBd` | только знак `>` в плашке |
| `Intro ` (с пробелом в конце) | римские цифры в круге |

Все четыре вшиты в шаблон (`p:embeddedFontLst`), поэтому файл открывается на
чужой машине. Имена гарнитур в pptx должны совпадать с вшитыми — если написать
`Akrobat` вместо `Akrobat Bold`, вшитый шрифт не подхватится.

## Рамки

| Элемент | x | ширина |
|---|---|---|
| Заголовок раздела, крупная мысль | 1028125 | 10480028 |
| Списки, текст стиха | 1022693 | 10508225 |
| Плашка `>` | 645485 (y = 474510) | 11169298 |
| Куплет гимна | 457200 | 11277600 |
| Круг с цифрой | 1201598, y = 492852 | 2239836 × 2252997, контур 38100 EMU жёлтым |
| Надпись с цифрой | 1386285 | 1870516 |

Отступ под номер пункта `marL` = 800100 (`indent` = −800100), маркер
`buAutoNum type="arabicPeriod"`, цвет маркера `bg1`, размер 80 %.

Вертикаль: блок заголовка раздела центрируется по 5,28", список — по 4,35",
крупная мысль — по 3,75", стих и `callout` — по 4,15". У нарастающих списков
верх фиксирован (`top_in=1.70`), блок растёт вниз.

## Кегли

| | |
|---|---|
| Титул | 138–150 жёлтым, подзаголовок 66–96, ссылка на текст 48 |
| Заголовок раздела | 88–115, максимум 2 строки |
| Пункт списка | 60, при нехватке места 54 / 48 / 44 |
| Плашка `>` | 48 |
| Стих | 60 → 40 |
| Гимн | 54, подпись автора 36 |

Межстрочный: 0,8 у заголовков, 0,9 у списков и текста. Отступ после пункта —
24pt, для перечней от пяти пунктов — 12pt.

## Как считается высота

Формула выверена по шести рамкам шаблона и сходится с точностью до пункта:

```
высота = Σ по абзацам (строк × кегль × 1.213 × межстрочный)
       + отступы между абзацами + 7.2pt (поля надписи)
```

`1.213` — множитель высоты строки, который применяет PowerPoint; он не
совпадает ни с `hhea`, ни с `OS/2` шрифта, поэтому подобран по факту.

Ширина строки считается по вшитым метрикам `assets/font_metrics.json`;
локальные шрифты через `fontTools` используются только как резерв (`textmetrics.py`), кернинг игнорируется — запас это перекрывает.

**Отдельно проверяй самое длинное слово.** Если оно шире строки, PowerPoint
рвёт его посередине, и текст уползает за нижний край слайда. Именно так
«УМИЛОСТИВЛЕНИЕ» на 115pt однажды разъехалось на три строки. `fit_size` и
`bullets` этот случай уже отсеивают через `word_fits`.

## Приёмы, которые стоит сохранять

- **Нарастающий список.** Заключительный перечень раскрывается по пункту на
  слайд. Верх блока фиксирован, поэтому уже показанные пункты не двигаются.
- **Жёлтый акцент внутри строки.** В крупной мысли одно-два слова жёлтым:
  «ХРИСТОС – НЕ ТОЛЬКО ПРИМЕР, **НО И ЖЕРТВА**».
- **Ссылка на Писание на титуле.** В референсах ключевой текст проповеди стоит
  третьей строкой титульного слайда: «2 Петра 1:12-15», «1 Коринфянам 15 глава».
- **Пустое место — это нормально.** Блок не растягивается на весь слайд;
  внизу справа остаётся воздух с логотипом.
